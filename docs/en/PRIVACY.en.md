# Privacy Policy

API-Xray (hereinafter referred to as "this extension") is designed with the user's privacy as our top priority. The handling of data within this extension is described below.

## 1. Data Collection and External Transmission
This extension **does not collect any** of your personal information, browsing history, or communication data (including API requests/responses, authentication tokens, JWTs, etc.). Furthermore, it will **100% never transmit** any of this data to external third-party servers.

## 2. Purpose of Data Use
All API logs and data captured by this extension are processed and displayed strictly within the user's browser (local environment). No third party, including the developer, can access this data.
