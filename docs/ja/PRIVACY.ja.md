# プライバシーポリシー (Privacy Policy)

API-Xray（以下、「本拡張機能」）は、ユーザーのプライバシーを最優先に考えて設計されています。本拡張機能におけるデータの取り扱いについて、以下の通り記述します。

## 1. データの収集および送信について
本拡張機能は、ユーザーの個人情報、閲覧履歴、および通信データ（APIのリクエスト/レスポンス、認証トークン、JWTなど）を**一切収集しません。**また、それらのデータを外部の第三者サーバーに送信することは**100%ありません。**

## 2. データの利用目的
本拡張機能がキャプチャしたすべてのAPIログおよびデータは、ユーザーのブラウザ（ローカル環境）内のみで処理・表示され、開発者を含む第三者がそれらのデータにアクセスすることはできません。
