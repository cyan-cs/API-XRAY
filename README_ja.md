# API-Xray

### [English Document](./README.md)
MITライセンスのもとで公開されている、完全オープンソースのブラウザ拡張機能向け開発者ツールです。APIのリクエスト/レスポンスログをリアルタイムでキャプチャ・検査・分析し、インスタントJWTデコーダーやcURLコマンド生成などの強力な機能を提供します。  
Copyright (c) 2026-present cyan-cs

## 1. 主な機能
- **リアルタイムAPIトラッキング:** すっきりとしたUIで、リクエスト履歴、ステータスコード、メソッドを瞬時にキャプチャして表示します。
- **インスタントJWTデコーダー:** Authorizationヘッダーを自動検出し、ペイロードのクレーム（中身）の抽出や、トークンの有効期限（エクスパイア）をその場でチェックします。
- **呼び出し頻度統計:** エンドポイントごとの呼び出し頻度を可視化し、パフォーマンスのボトルネックを即座に発見できます。
- **開発者向けユーティリティ:** レスポンスJSONのコピー、フルログのダウンロード、正確な `cURL` コマンドの生成がワンクリックで可能です。

## 2. インストール方法

### 🌐 Chromeウェブストアからインストール
公式ストアから安定版を直接インストールできます：

[Available in the Chrome Web Store](https://chromewebstore.google.com/detail/api-xray/bckoaldclpjipijnecncmdobjiihfabm)

### 🛠️ 手動インストール（ソースコードからビルド）
本拡張機能はPlasmoで構築されているため、パッケージ化されていない拡張機能としてブラウザに読み込ませることも可能です：

1. このリポジトリをダウンロードまたはクローンします。
2. `npm install` および `npm run build` を実行して、本番用のビルドを生成します。
3. Chromeを開き、`chrome://extensions/` に移動します。
4. 画面右上の **「デベロッパー モード」** を有効にします。
5. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、`build/chrome-mv3-prod` フォルダを選択します。

## 3. ビルドと開発

本プロジェクトでは、標準のパッケージマネージャーとして **npm** を使用しています。

### 開発モード（ライブリロード）

コードの変更をリアルタイムに反映しながら開発する場合：
```bash
npm run dev
```

### 本番用ビルド
拡張機能を最適化してコンパイル・バンドルする場合：
```bash
npm run build
```

## 4. 構成 & ワークフロー
- ESLint & Prettier: コードベースをクリーンに保つため、標準化された設定ファイル（`.eslintrc.json`, `.prettierrc.mjs`）が含まれています。
- GitHub Actions: Chrome Web Store等への自動パブリッシュ（Plasmo BPP）に対応した、本番環境向けのCI/CDワークフロー（任意設定）が含まれています。
