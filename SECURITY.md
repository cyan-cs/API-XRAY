# Security Policy

## Supported Versions

We officially support the latest stable version of API-Xray. Security updates and bug fixes will be provided exclusively for the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.0| :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it to us immediately to help keep our community safe.

### How to Report
Please report security vulnerabilities by **opening a GitHub Issue** in this repository. To protect user privacy, do not include sensitive data or credentials in your report.

### What to Expect
- **Acknowledgment:** We will review your report and acknowledge it as soon as possible.
- **Updates:** You will receive regular progress updates until the issue is resolved.
- **Resolution:** If accepted, a security patch will be released in the next version as quickly as possible.
